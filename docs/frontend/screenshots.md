# 실제 사용 화면

운영 API와 연결한 로컬 프로덕션 실행 환경에서 캡처한 주요 사용자 화면이다.

## 시장 단가 분석 대시보드

사용자 단가를 시장 중앙값, 분위수 밴드, 단가 분포 그래프로 비교한다.

![시장 단가 분석 대시보드](/img/screenshots/dashboard-chart.jpg)

## 스마트 견적 계산기

직무, 경력, 작업 범위, 플랫폼, 산출물 조건을 대화형 플로우로 입력하고 권장 견적을 산출한다.

![스마트 견적 계산기](/img/screenshots/estimate-flow.jpg)

## 커뮤니티

디자이너들이 실무, 세무, 외주 협상, 포트폴리오 관련 정보를 나누는 게시글 목록 화면이다.

![커뮤니티](/img/screenshots/community.jpg)

## 커리어 관리

사용자의 직군, 경력, 자격증 정보를 확인하고 단가 기록과 견적서 보관함을 관리한다.

![커리어 관리](/img/screenshots/career.jpg)
